# SQLProject-CreateDatabaseSystems-DataModeling


Problem Statement:
    You are tasked with developing database systems for five distinct scenarios, each presenting unique requirements and constraints. Your goal is to design, implement, and manage databases that effectively address the specific needs of each case study.

Applications used for this project :
    PostgreSQL
    PgAdmin
    Docker

Objectives:
    Design comprehensive database schemas for each case study.
    Implement the database schemas using PostgreSQL.
    Ensure data integrity and implement appropriate constraints.
    Use PgAdmin for database management and visualization.
    Utilise Docker to containerise your PostgreSQL database, ensuring a consistent and isolated environment for your work.


For each case study, you are expected to provide:
    A detailed database schema diagram (The ER Diagram).
    SQL scripts for creating tables, constraints, and relationships.
    A brief README.md report explaining your design decisions, challenges faced, and how you addressed them. 
    A Docker-compose.yml file and instructions on how to build and run your PostgreSQL database in Docker.

The correctness and efficiency of the database design will be based on:
    Effective use of PostgreSQL features.
    Clarity and thoroughness in documentation and reports.
    Successful implementation of Docker for database containerization.

Submission :
    Submit your deliverables via the designated submission platform.
    Ensure that all codes and reports are clearly labeled for each case study.
